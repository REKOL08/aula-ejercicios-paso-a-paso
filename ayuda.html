GUÍA DE USO Y ALCANCE

Comprende antes de entregar.

Elige un tipo de ejercicio, introduce los coeficientes de tu enunciado y escribe tu respuesta si quieres compararla. Pulsa Resolver y verificar. Cada resultado incluye operaciones intermedias.

Qué puedes consultar

  • Ecuación lineal: a·x + b = c.
  • Ecuación cuadrática: a·x² + b·x + c = 0. Solo soluciones reales.
  • Regla de tres directa: a / b = c / x. Los tres valores deben ser distintos de cero.
  • Porcentaje: cantidad × porcentaje / 100.
  • Sistema de dos ecuaciones: a·x + b·y = c; d·x + e·y = f.

Cómo escribir una respuesta

Escribe un decimal, como 2,5 o 2.5. Para dos raíces, escribe ambas separadas por punto y coma: 2; 3; el orden no importa. Para un sistema, el orden es x; y. Para los casos especiales usa sin solución o infinitas.

La tolerancia de comparación es 10⁻⁶ × máximo(1, valor absoluto de la respuesta esperada). Las fracciones deben convertirse a decimal. El resultado mostrado se redondea a nueve cifras significativas, pero la comparación usa la precisión interna.

Alcance honesto

No hay inteligencia artificial generativa ni interpretación de preguntas libres. La aplicación valida únicamente los cinco modelos descritos. No califica ensayos, demostraciones, tareas de otras disciplinas, unidades o la interpretación del enunciado. Los números se calculan con la precisión limitada de JavaScript; coeficientes extremadamente pequeños, sistemas casi singulares y cancelación pueden perder precisión. Usa valores moderados para ejercicios de aula.

Tus datos

El último ejercicio se guarda en localStorage de este navegador. No se sincroniza entre dispositivos ni se envía a terceros. Borrar los datos del navegador elimina ese guardado. Exporta un archivo JSON para conservarlo o trasladarlo. Antes de importar o borrar se pide confirmación. Si el navegador impide guardar, verás un aviso y podrás seguir calculando.

GitHub sirve la página y puede registrar solicitudes de acceso según sus políticas. La aplicación no incluye analítica, cookies propias, rastreadores, fuentes remotas ni dependencias externas.
