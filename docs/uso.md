# Uso

1. Abre el enlace GitHub Pages del README desde computador o celular.
2. Selecciona uno de los cinco modelos y transcribe los coeficientes, incluyendo sus signos.
3. Opcionalmente escribe tu respuesta. Usa decimales; separa dos respuestas con `;`. En sistemas el orden es x; y. En cuadráticas no importa el orden de las raíces.
4. Pulsa Resolver y verificar. Lee cada paso y contrasta con tu planteamiento.
5. Exporta un respaldo JSON si necesitas llevar el ejercicio a otro navegador. Importar reemplaza el actual después de una confirmación.

Ejemplos: `2x + 3 = 11` produce x = 4. `x² − 5x + 6 = 0` produce x = 2 y x = 3. `2x + y = 7; x − y = 2` produce x = 3, y = 1.

No necesitas cuenta ni instalación. Hace falta conexión para cargar inicialmente la página; no se garantiza modo sin conexión. Datos guardados pertenecen al navegador y al origen, no a una cuenta institucional.
