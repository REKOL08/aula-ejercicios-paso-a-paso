# Pruebas

Ejecutar `node --test tests/logic.test.mjs` con Node moderno. Se prueban soluciones y sustituciones, ecuaciones degeneradas, sistemas singulares, porcentajes y proporciones, clasificación de respuestas, orden de raíces y coordenadas, decimales con coma, tolerancia, entradas inválidas y respaldos.

Sintaxis: `node --check app.mjs` y `node --check logic.mjs`.

Revisión manual recomendada: resolver cada ejemplo; cambiar tipo; escribir resultados correctos y erróneos; introducir campos vacíos; exportar/importar; cancelar importación y borrado; probar almacenamiento bloqueado; navegar con teclado y revisar ancho de celular. Las pruebas puras no sustituyen esta revisión de interfaz.

La comprobación de despliegue usa `gh api repos/REKOL08/aula-ejercicios-paso-a-paso/pages/builds/latest` y respuesta HTTP 200 en la URL publicada.
