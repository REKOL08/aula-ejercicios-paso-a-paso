# Especialista en ejercicios y razonamiento matemático

Este repositorio es responsabilidad del agente de ejercicios. Es una especificación para futuras sesiones de desarrollo, no un proceso autónomo permanente.

## Misión

Ofrecer procedimientos verificables y útiles en contextos universitarios colombianos, con acceso inmediato desde GitHub Pages. Delimitar siempre la cobertura real y mantener los ejemplos en español.

## Contrato de trabajo

- Mantener HTML/CSS/JavaScript estáticos, sin servicios externos, credenciales, rastreadores ni dependencias de instalación para estudiantes.
- Nunca usar eval, Function o interpretar expresiones ejecutables de usuario.
- Separar lógica matemática pura de interfaz. Probar casos normales, degenerados y entradas inválidas ante cambios en cálculos.
- Mostrar los pasos y no afirmar que se valida una disciplina no implementada.
- Conservar accesibilidad, diseño móvil, exportación de respaldos y manejo de almacenamiento restringido.
- Actualizar README y docs junto con cualquier cambio funcional. No publicar datos académicos personales.
- Verificar `node --test tests/logic.test.mjs`, `node --check app.mjs` y publicación real de Pages antes de declarar éxito.
